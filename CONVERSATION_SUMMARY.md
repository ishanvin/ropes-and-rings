# Accessories Boutique Project Summary

## Project Overview
A fully functional mockup of an online accessories store with a boutique aesthetic, focused on direct customer engagement via WhatsApp.

## Implemented Features
- **Modern Homepage:** Elegant hero section and category discovery.
- **Product Catalog:** Full shop with search and filtering for Bands, Hair Accessories, and Jewelry.
- **WhatsApp Integration:** Direct "Order via WhatsApp" buttons on every product.
- **Admin Dashboard:** Interface to add, edit, or delete products in real-time.
- **Responsive Design:** Optimized for both mobile and desktop.

## Tech Stack
- **Frontend:** React + TypeScript (Vite)
- **Styling:** Vanilla CSS with custom properties for a cohesive theme.
- **State Management:** React Context API for products and mock authentication.
- **Routing:** React Router.

## How to Run the Website
To view your website in the future, follow these steps:
1. Open your terminal.
2. Navigate to the project folder: `cd accessories-boutique`
3. Run the development server: `npm run dev`
4. Open the link provided in your browser (usually `http://localhost:5173`).

## Key Files
- `src/data/products.json`: Initial product database.
- `src/context/StoreContext.tsx`: Manages the global product and user state.
- `src/styles/global.css`: Contains the boutique theme and colors.
- `src/pages/AdminDashboard.tsx`: The management interface.
